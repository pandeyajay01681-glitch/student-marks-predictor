
# Student Performance Predictor

An interactive machine learning web application built
with Python, NumPy, and Streamlit.

## Features
- NumPy-based linear regression
- Gradient descent optimization
- Feature normalization
- Interactive study-hours and attendance inputs
- Real-time score predictions
- Mean squared error display

## Technologies
- Python
- NumPy
- Streamlit

## How to run locally

1. Clone this repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Launch the application:

   streamlit run app.py

## Machine Learning
The model is trained on synthetic data using gradient
descent. Its outputs are educational demonstrations,
not validated academic predictions.
